# Homebrew Formula for [`krateoctl`](https://github.com/krateoplatformops/krateoctl)

```sh
brew tap krateoplatformops/krateoctl
brew install krateoctl
```

or if you have already installed [`krateoctl`](https://github.com/krateoplatformops/krateoctl) using brew, you can upgrade it by running:

```sh
brew upgrade krateoctl
```
